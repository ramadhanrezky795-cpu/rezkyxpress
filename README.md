# Rezkyxpress

A modern storefront and landing page for the Rezkyxpress brand.

## Cara menjalankan

Buka langsung file:

- `app/index.html`

Atau jalankan lokal dengan server static:

```bash
cd app
python3 -m http.server 8000
```

Lalu buka:

- `http://localhost:8000`
